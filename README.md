# Presentation Next.js

Site para apresentação do perfil profissional.

## Instalação

```bash
pnpm install
```

## Configuração

```bash
# Copiar o arquivo de exemplo para o arquivo de ambiente
cp .env.example .env.local
```

## Iniciar o projeto

```bash
pnpm dev
```

## Compilação e execução

```bash
# Gerar a build do projeto
pnpm build

# Executar a build do projeto
pnpm start
```

## Linters

```bash
# Verificar erros com ESlint
pnpm lint

# Verificar erros com Prettier
pnpm format:check

# Verificar erros com TypeScript
pnpm type-check
```
